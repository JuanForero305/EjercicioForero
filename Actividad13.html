Demostración del uso de iframe en HTML5

Este ejercicio muestra cómo utilizar la etiqueta <iframe> en HTML5 para incrustar contenido externo.

Google Maps - Ubicación de Tamarindo Salado, San Bernardo, Tolima

CARACOL

La etiqueta <iframe> se utiliza en HTML5 para incrustar contenido externo dentro de una página web. Permite mostrar contenido de otras páginas web, como mapas, videos, documentos y más, directamente dentro de tu sitio web.
